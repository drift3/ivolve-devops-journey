# Build Tools

This directory contains my hands-on build tool labs as part of the iVolve DevOps training.

The exercises focus on building, testing, and packaging applications using different build automation tools.

### Completed Labs

- **Lab 1 – Maven:** Built, tested, and packaged a Java calculator application using Maven.
- **Lab 2 – Gradle:** Built, tested, and packaged a Java calculator application using Gradle.

Each lab has its own directory with the project files and a README documenting the implementation and results.

More labs and exercises will be added as I progress through the training.
