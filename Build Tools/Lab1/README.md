# Lab 1: Building and Packaging a Java Application with Maven

In this lab, I built and tested a Java calculator application using Maven on RHEL.

### What I did
- Verified Java and Maven installations.
- Ran unit tests using `mvn test`.
- Packaged the application using `mvn package`.
- Generated the JAR file at `target/calculator.jar`.
- Ran the application using `java -jar target/calculator.jar` and verified the calculation results.

All five unit tests passed, and the application ran successfully.
