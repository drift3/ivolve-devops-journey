# Lab 2: Building and Packaging an Application with Gradle

In this lab, I built and tested a Java calculator application using Gradle on RHEL.

### What I did
- Ran unit tests using `gradle test`.
- Built the application using `gradle build`.
- Generated the JAR file at `build/libs/calculator.jar`.
- Ran the application using `java -jar build/libs/calculator.jar` and verified the calculation results.

Both the tests and build completed successfully.

Note: The provided repository contains a Java application, although the original lab description mentions Go.
